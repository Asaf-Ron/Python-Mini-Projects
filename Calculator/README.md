CLI Calculator

Description

This is a simple CLI calculator application that I built using Python.
The calculator allows the user to perform basic mathematical operations while handling invalid inputs and common errors.

The user can perform multiple calculations without restarting the program, and the calculator keeps a history of successful calculations.

Features

* Supports addition, subtraction, multiplication, and division.
* Validates number inputs and prevents the program from crashing when invalid input is entered.
* Validates mathematical operations.
* Handles division by zero without crashing.
* Allows the user to perform multiple calculations in the same session.
* Stores successful calculations in a history list.
* Displays a numbered calculation history when the user finishes.
* Handles an empty calculation history.

How to Run

Run the program from the terminal:

python3 calculator.py

Then follow the instructions displayed in the terminal.
